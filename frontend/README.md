# PeoplePay360 - Frontend

Next.js 15 enterprise payroll & human resource operations portal built with TypeScript, Tailwind CSS, and Lucide icons.

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run development server:
```bash
npm run dev
```

Default URL: http://localhost:3000
API Gateway rewrites: http://localhost:8080/api/v1
